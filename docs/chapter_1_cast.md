# Chapter 1 Cast and Dialogue Counts

## Scope

This report covers every dialogue row exported by Ren'Py for
`game/script.rpy`, the Chapter 1 main-story script selected by
[`configs/pipeline.toml`](../configs/pipeline.toml). The export was generated
from `LessonsInLove0.60.0-0.60.0-pc-subscribestar`.

Character identifiers come from the export's `Character` column. Display names
are resolved through [`configs/characters.toml`](../configs/characters.toml).
An empty `Character` value denotes narration and is reported using the project's
built-in `narrator` ID; `narrator` is not a literal speaker variable on those
source lines.

Counts are raw dialogue entries before semantic cleaning, omission, or TTS
decisions.
